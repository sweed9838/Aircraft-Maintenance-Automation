# Aircraft Maintenance Discrepancy Tracker
## Project Description
This python program tracks aircraft maintenance discrepancies and displays a summary of open and closed maintenance records.
The project was created to practice python programming and version control using Git and Github

## Features
-Displays aircraft maintenance discrepancies
-Shows aircraft numbers and reported issues
-Identifies open and closed discrepancies
-Calculates the total number of maintenance records
-Counts open and closed maintenance discrepancies

## Programs Used
-Python 3
- Git
- GitHub

  ## How to Run
  1. Download the python file from this repository.
  2. Make sure python 3 is installed
  3. Open terminal in the project folder
  4. Run the following command:
 
  python maintenance_tracker.py

  ## Purpose
  This project demonstres basic python programming includes lists dictionaries , loops and conditional statements. It also demonstrates version control through commits , branches , and pull request.
